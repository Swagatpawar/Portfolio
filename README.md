# Swagat Pawar — Portfolio

A responsive, static portfolio built in the established immersive dark, liquid-inspired visual direction. The page is plain HTML, CSS, and JavaScript; no build step or framework is required.

## Preview

Open `index.html` in a browser. The typefaces load from Google Fonts, with system fallbacks if they are unavailable.

## Included content

- Hero, About, Featured Projects, Education, Technical Skills, Experience, Achievements and Leadership, and Contact sections.
- PlantGuard AI application screenshot from the local project at `Desktop/Plant/screenshots/plantguard-prediction.png`.
- FarmSaathi field photo from the existing FarmSaathi frontend assets.
- Original CSS artwork for CineMatch and Saathi AI. These visuals are not presented as application screenshots.
- Project source links for PlantGuard AI, CineMatch, FarmSaathi, GitHub, and LinkedIn.
- Reported project metrics with context and appropriate limitations.
- Responsive navigation, scroll reveals, liquid-line canvas, focus states, and reduced-motion support.
